## Cách lấy sơ đồ schema từ Supabase

1. Vào Supabase Dashboard → project nim-movie.
2. Sidebar → **Database** → **Schema Visualizer** (hoặc **Table Editor** → biểu tượng diagram).
3. Chọn schema `public` → export PNG.
4. Đặt vào file này: `database-schema.png`.

## Mẹo

- Dùng PNG hoặc WebP, nén qua [TinyPNG](https://tinypng.com) để repo nhẹ.
- Nếu screenshot có thông tin nhạy cảm (email thật, token), nhớ blur trước khi commit.
- Tên file viết kebab-case, không khoảng trắng, không dấu tiếng Việt.
